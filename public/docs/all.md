# The Shelf 产品需求

The Shelf 让收藏中的每一本书都能被找到，即使电子书暂时没有上传。公开访问者可以查看分类目录、书籍基本信息和已发布内容；所有者登录后可以阅读私有书籍、提问和管理收藏。

更新日期：2026 年 10 月 13 日。阶段：设计。

## 用户与权限

| 操作 | 公开访问者 | 所有者 |
| --- | --- | --- |
| 查看书架、搜索分类与书籍详情 | 允许 | 允许 |
| 阅读公开产品与实现文档 | 允许，无需登录 | 允许 |
| 查看主动发布的 AI 总结 | 允许 | 允许 |
| 阅读或下载私有云端书籍 | 不允许 | 登录后允许 |
| 阅读或下载已确认允许公开的文件 | 允许 | 允许 |
| 请求 AI 回答或生成总结 | 默认不允许 | 登录后允许 |
| 修改分类、文件可见性和公开总结 | 不允许 | 登录后允许 |

公开文件与开放 AI 调用是不同权限。公开一本书不会同时开放所有者的 AI 额度。

## 书架与搜索

首页提供书名、作者、格式、主分类、标签和文件状态的筛选。初期搜索目录、人工简介与已发布总结。全文索引仅用于有权限的书内问答，不发布为静态资源。

采用主分类加多个标签。可以用原始文件夹作为分类建议，但保留所有者的人工修正，不把每次重新导入当成重置。

同一作品的多个格式归到同一详情页。译本、语言和版本差异分别保留；相同文件用校验值去重，相同书籍不能只凭标题自动合并。

## 书籍详情

详情页显示书名、作者、版本、分类、标签、允许展示的封面与简介，以及文件列表。

| 文件 | 格式 | 大小 | 状态 | 操作 |
| --- | --- | --- | --- | --- |
| 示例阅读版 | EPUB | 3 MB | 已上传，仅所有者可用 | 登录后阅读或下载 |
| 示例原版 | PDF | 120 MB | 仅本地保存，因大小暂未上传 | 查看文件信息 |

示例中的文件并非实际扫描结果。超过门槛的文件列出大小和格式，明确说明暂未上传，不提供指向本机磁盘的网页链接。无云端文件时，仍保留完整目录记录。

拥有多个格式的书按文件分别判断上传资格。大 PDF 不阻止小 EPUB 上传；某个格式在云端可用，也不意味着其他格式已经上传。

## 在线阅读

PDF 保留页面排版，支持目录、页码和缩放。EPUB 提供目录、字号、主题和阅读位置。MOBI、AZW 和 AZW3 保留原文件，必要时产生 EPUB 阅读版本。

阅读器与下载接口使用同一套权限。私人文件必须经后端授权；只隐藏下载按钮不构成访问控制。第一版阅读进度可以保存在浏览器，跨设备同步后续增加。

## AI 功能

详情页提供自由提问、章节总结、全书总结和作者资料整理。导入和打开页面均不自动调用 LLM。

只有已准备正文的书才能回答书内问题或总结正文。仅有目录记录的书仍可整理有来源的作者资料，但不能假装已读过正文。

生成结果自动保存在个人记录中；所有者选择发布后才成为公开详情内容。正式总结与私人对话分开保存。

## 文件公开条件

文件默认私有，版权状态默认待确认。记录许可、授权来源、适用版本和使用范围后，再由所有者明确开放文件。译本、插图和封面需要各自适用的依据。

网络上存在免费下载不表示可以重新分发。[WIPO 版权常见问题](https://www.wipo.int/en/web/copyright/faq-copyright) 解释了网络作品、许可和公有领域的区别。AI 不能代替具体文件版本的权利核验。

## 第一版不包含的能力

暂不开放匿名 AI 请求，不建设付费功能或多用户协作，不批量为所有收藏生成摘要。超过大小门槛的文件暂不上传、不做自动 OCR，也不为其自动上传提取正文。

# The Shelf 系统架构

公开目录和文档使用静态网页；私人文件访问与按需 AI 使用由独立业务后端处理。大文件留在本地时，云端只保留公开目录所需的信息。

更新日期：2026 年 10 月 15 日。阶段：首版实现；CF-02 静态配置待验收，尚未切换现有发布。

## 组件职责

| 组件 | 职责 | 初期选择 |
| --- | --- | --- |
| 网页 | 书架、详情、阅读器、问答界面和公开文档 | GitHub Pages，静态构建；Workers Static Assets 配置已准备，待验收 |
| 本机导入 | 扫描、元数据提取、去重、格式转换和文本准备 | 本机执行，不调用 LLM |
| 文件存储 | 云端原文件和必要的阅读版本 | R2 Standard，受免费预算约束 |
| 书库后端 | 所有者登录、文件授权、任务创建和结果查询 | Node.js 独立轻量服务；生产部署位置待定 |
| 业务数据库 | 书籍、文件、任务、问答、正文索引和公开结果 | SQLite，适配中文检索 |
| 后台任务 | 准备输入、调用 AI、保存结果和控制并发 | 有上限的持久队列，初期串行调用 |
| AI 服务 | 根据输入文本生成结果 | 现有 oai-api 命名任务接口 |

静态前端采用 Astro 和 TypeScript。目录与文档均可直接生成 HTML。paw 是开发机器，现有 Node.js 后端尚未部署为生产服务；下一阶段的 Cloudflare 目标如下。

## Cloudflare 迁移目标

2026 年 10 月 15 日确认将 Cloudflare 统一托管纳入后续计划。静态迁移代码和目标 URL 已进入本轮验收；下表中的 API、D1、R2 业务绑定和 Workflows 仍是待验证目标，不能视为已经部署。

| 组件 | 目标 | 迁移变化 |
| --- | --- | --- |
| 静态网站 | Workers Static Assets，目标 URL `https://the-shelf.iamzhutuo.workers.dev/` | 继续使用 Astro 构建；静态产物验收后再决定替代 Pages 发布 |
| 业务 API | Workers，同站点 /api/ | 适配请求处理、登录、文件授权与元数据接口 |
| 业务数据 | D1 | 适配本地 SQLite、内存会话和 JSON 覆盖记录；只导出允许公开的字段用于构建 |
| 原文件与准备好的正文 | 现有私有 R2 | 保留逐文件授权和预算；正文与派生文件计入相同存储预算 |
| 后台 AI 任务 | Workflows | 显式配置超时与重试，保存任务状态和结果，不依赖浏览器连接 |
| 文件导入与正文提取 | paw 本机工具 | PDF 与 EPUB 正文在本机准备后按文件同步；不在 Worker 中启动系统子进程 |
| AI 推理 | 现有 oai-api | 继续独立配置专用任务 Key，不增加模型订阅 |

先验证免费 CPU、D1 持久化与长任务执行，再迁移静态网站、私人阅读和 AI。Cloudflare 服务绑定不能直接替代现有 Node.js 文件系统与 SQLite 调用；实施顺序与门槛见[开发计划](development-plan.md)。paw 继续承担开发和导入，生产资源的实际地址及部署方式以验证结果确定。

## 数据归属

| 数据 | 位置与公开范围 |
| --- | --- |
| 产品和实现文档 | 仓库内容源，公开网站发布 |
| 公开目录 | 经过字段筛选的静态快照 |
| 原始文件与阅读版本 | 本地或私有对象存储，按文件授权 |
| 本机绝对路径和导入清单 | 本机私人状态，不进入公开构建 |
| 提取正文和全文索引 | 私人业务存储，仅授权任务读取 |
| 私人对话和未发布总结 | 业务数据库，仅所有者读取 |
| 已发布总结 | 独立公开投影，可供详情页读取 |
| AI Key 和存储凭证 | 后端配置，不进入浏览器和仓库 |

公开投影采用允许字段清单；不能直接把业务数据库整表或私人清单导出到静态目录。

迁移后 D1 保存业务状态和必要索引，较大的正文存入私有 R2；业务数据从本机迁出前先备份和核对，保留原有私人映射与人工修正。云端密钥使用服务端秘密配置，不进入公开目录或网站。

## 文件访问

后端先验证所有者会话和文件权限，再返回短期签名链接。公开文件使用单独的公开入口。原始存储桶默认不开放匿名访问。

阅读器支持链接刷新与 PDF Range 请求。跨域配置只允许预期网站来源；CORS 是浏览器访问规则，不代替后端鉴权。

短期签名链接在有效期内具有访问能力，不能写进静态页面、公共日志或公开文档。[R2 签名链接说明](https://developers.cloudflare.com/r2/api/s3/presigned-urls/)。

## AI 任务生命周期

网页创建业务任务后立即得到业务任务 ID，通过查询接口读取排队、执行、完成或失败状态。后台工作进程持有对 oai-api 的长请求；网页关闭不直接断开该请求。

业务任务 ID 与 oai-api 完成后返回的上游 turn ID 分开保存。后者不能用于上游查询进度或恢复回答。

成功输出完成校验后原子保存。重新启动时恢复待执行任务；执行中的任务若结果不可确认，标记待确认而非自动再次消耗额度。

以上是现有 Node.js 队列行为。迁到 Workflows 时保留相同业务约束和串行调用预算，不能直接沿用平台默认重试；调度持久化不意味着上游请求可以安全重放。

## 发布与可用性

目录、文档和人工修订经过静态构建发布到 Pages。AI 回答写入数据库后，私人详情界面立即可读；主动发布的内容可通过公开接口读取，并在后续构建同步为静态内容。

迁移完成后，静态产物发布目标改为 Workers Static Assets，D1 中的人工修订通过公开字段快照进入下一次构建。切换前验证站点基路径、同源 API、R2 CORS 与回退方案；当前 GitHub Pages 发布仍有效。

AI 服务不可用时，目录、文档、已保存总结和已授权文件仍能独立访问。

GitHub Pages 本身只提供静态托管，没有业务数据库写入能力。[官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

# The Shelf 导入与存储策略

所有电子书文件都进入收藏清单，但不保证都进入云端。上传资格由文件稳定性、单文件大小、总存储预算和人工选择共同决定。

更新日期：2026 年 10 月 13 日。阶段：设计。

## 大小门槛

默认门槛为 20 MB，按十进制定义为 20,000,000 字节。大于门槛的文件仅登记，小于或等于门槛的完整文件进入上传候选列表。

门槛作用于每个文件，适用于所有格式。大 PDF 默认视为可能包含较多图片的文件并延后处理，但文件大小不是扫描 PDF 的检测结果。小文件也可能是扫描版。

对于同一本书，120 MB PDF 仅登记，3 MB EPUB 可以进入上传候选。书籍状态根据全部文件综合展示，不隐藏未上传格式。

转换后的文件也需要检查大小和总预算。大原文件的转换版或提取正文不自动绕过门槛；所有者另行选择处理后仍受相同存储预算约束。

## 文件状态

上传状态、访问权限和正文准备状态分开保存。

| 维度 | 状态示例 |
| --- | --- |
| 上传 | 复制中、待处理、候选、因大小延后、因预算延后、已上传、失败 |
| 访问 | 默认私有、确认可公开 |
| 正文 | 未准备、已提取、需要 OCR、解析失败、不可解密 |

详情页公开格式、大小和上传可用性。实际本机位置只在私人管理数据中保存。

## 复制期间的盘点

目录仍在复制时只读取目录项、文件大小和修改时间，不移动、删除、转换或上传源文件，也不对全部书籍计算大文件校验值。

至少比较两个时间点的路径、大小与修改时间。发生变化、新增或明显临时命名的文件标为待确认。短期不变化只能说明这一观察窗口稳定，不能证明复制已经完成。

正式导入需要复制完成，或通过完整性检查和稳定性检查后明确选取文件。提取前后再次检查状态变化，失败记录不阻断其他文件。

盘点统计文件数量和字节数，按格式与 20 MB 门槛汇总。文件数量不等于书籍数量，后续需要识别多格式、版本和重复文件。

## 导入顺序

1. 扫描支持的格式及未知扩展名，忽略系统附属文件。
2. 对完整文件提取书名、作者、版本与目录建议，保留人工修正。
3. 计算候选文件校验值并去重，不只用文件名判断重复。
4. 生成必要的 EPUB 阅读版本，避免默认上传所有派生文件。
5. 为选中的文件提取正文、章节和来源位置；需要 OCR 的文件延后处理。
6. 核算实际上传计划，检查预算后上传。
7. 校验远端结果，再标记云端可用；发布允许公开的目录信息。

任何阶段都不默认调用 LLM。重新扫描不会重新生成 AI 总结或重复上传相同文件。

## 免费额度约束

R2 Standard 当前每月免费额度为 10 GB-month 存储、100 万次 Class A 操作和 1,000 万次 Class B 操作，直接出站流量不收费。免费额度不适用于 Infrequent Access。[R2 官方价格](https://developers.cloudflare.com/r2/pricing/)。

20 MB 门槛不能单独保证落在免费额度内：700 个 15 MB 文件就需要约 10.5 GB。必须先用实际清单计算，再计入原文件、阅读版本、重复版本和同一账号的其他占用。

初期本项目目标使用量不超过 8 GB，保留至少 2 GB 余量；如果同一账号已有其他 R2 数据，按实际剩余额度进一步收紧。此数值是项目预算，不是平台强制限制。

[当前只读盘点](inventory.md)显示，核心电子书格式中不超过 20 MB 的文件合计约 5.29 GB。这个数字还没有排除损坏文件、重复版本，也没有加入转换文件；后续上传仍需逐批核算。

每批上传把现有占用、待上传批次和进行中上传预留合并核算。超出项目预算的候选文件继续只登记，绝不自动升级额度或购买容量。上传准入需要单一协调者或原子预算预留，避免并发任务同时判断尚有余额。

免费套餐并不是项目自动停止的保障。请求操作数也要监控，在项目设定的保守阈值前限制云端文件入口；目录和公开文档继续可用。平台计量延迟、其他客户端使用和直接文件访问需要纳入预算评估，不能声称仅凭应用限制就绝对不会产生账单。

GitHub Pages 只承载网页、目录与文档，电子书不进入部署包。Pages 发布站点的 1 GB 限制不能被 R2 免费存储额度替代。[Pages 限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)。

# The Shelf 收藏盘点

两次只读盘点表明，20 MB 门槛能让当前核心电子书格式的大小候选总量落在项目暂定的 8 GB 存储预算内。候选仍需检查完整性、重复版本和云端实际占用后才能上传。

更新日期：2026 年 10 月 14 日。状态：复制完成后已重新扫描。盘点没有读取正文、修改文件、转换格式或上传内容。

## 盘点范围与口径

两次扫描分别在 2026 年 10 月 13 日 14:34:05 UTC 和 15:12:24 UTC 观察目录。递归统计普通文件，跳过隐藏文件与符号链接。大小门槛为 20,000,000 字节，等于门槛的文件归入大小候选。

# The Shelf AI 问答与总结

AI 按所有者请求执行。导入只准备文件和检索数据，打开页面只读取已有结果。书内问答、全书总结和作者资料使用不同的材料来源。

更新日期：2026 年 10 月 13 日。阶段：设计。

## 现有服务接入

oai-api 当前使用 POST /v1/tasks 命名任务接口。输入是纯文本，返回 content 字符串、上游 turn ID，以及可能缺失的 token 用量。书籍总结可以使用 research_summary，书内分析使用 topic_analysis；接入时验证返回值，不把模型输出直接当作可信业务数据。

现有服务每次创建独立临时会话，不读取书籍文件，不自动抓取 URL，不联网检索，也不提供连续对话、业务任务查询或结果恢复。服务限额与请求约定见 [公开接入指南](https://oai.parallelstreamllc.com/guide)。

当前源码限制输入 500,000 字符，编码后的整个请求体默认不超过 4 MiB。这些只是接口上限，不等于模型可用上下文。全局默认并发为 1，文本任务期限默认 840 秒；繁忙时返回 503 和 Retry-After。

流式接口目前只接受 essay_correction，书籍问答不能冒用该类型。第一版显示业务任务进度和完成后的回答；以后若确有必要，再明确扩展服务任务类型与流式契约。

## 专用 Key

书库使用独立命名 Key，只保存在业务后端。当前任务服务验证环境配置中的 Key，旧管理页数据库签发的 Key 不能直接用于新任务入口。

Key 提供调用归属，不等于书籍权限、用户登录或独立配额。所有者登录、每日调用限制和任务预算在书库后端实现。签发与部署配置属于实现阶段，不在设计阶段执行。

## 书内问答

按书籍范围检索正文，使用适合中文的分词或检索方式，结合章节标题、相关段落和必要的对话历史准备材料。回答提供章节或 PDF 页码来源；EPUB 使用章节与稳定定位，避免虚构固定页码。

找不到依据时说明无法从已准备正文确认，不把模型已有知识伪装成原文。只登记而未准备正文的书不开放书内问答；用户可另行请求作者资料或背景研究。

书中出现的指令、网址和提示词按材料处理，不改变系统约束。私有书籍的正文片段与问答记录不进入公共缓存。

## 全书与章节总结

章节总结只处理选定章节。全书总结按章节和模型输入预算处理，保存中间结果后生成总览。已有相同版本结果可以直接读取，修改的章节单独重新处理。

目录、前言或节选可以生成内容概览，但不能标为全书总结。长书任务显示覆盖范围、预计调用次数和额度提示；超过项目设定上限时缩小范围或暂停，不能悄悄启动无限分块任务。

## 作者资料

作者生平需要独立的资料获取步骤，优先使用可以确认作者身份且允许使用的公开来源。记录来源 URL、获取时间和适用许可，再让现有 AI 服务根据资料整理。

同名作者需要结合作品、语言和年代核对。资料不足时显示已有事实及缺口，不由模型补齐不存在的来源。没有正文的书也可以使用此能力。

## 保存与发布

任务成功后默认保存为所有者私有记录。正式总结和对话记录分别存储，所有者主动选择后才生成公共版本。公开版本保留出处和覆盖范围，避免发布大段原文。

缓存标识包含书籍版本、来源内容校验值、操作类型、章节范围、问题、模型与生成设置。缓存复用必须先验证访问权限；普通问题不只靠相似问题文本自动复用不同语境的回答。

## 队列与额度

书库建立有上限的持久队列，初期只并行调用一个 AI 请求，并遵守现有服务的 Retry-After。相同在途业务任务去重，页面刷新和重复点击不创建新的调用。

只有业务层负责重试，避免与 HTTP 客户端叠加。明确的忙碌拒绝可以有限退避；超时、断线或其他结果不确定的情况标记待确认，不自动重新调用。现有服务没有上游幂等或恢复能力，不能承诺每个任务严格只执行一次。

使用已有订阅服务控制调用与额度占用，不自动购买官方 API 余额、向量服务、联网检索套餐或其他模型订阅。需要付费依赖时先暂停该能力，保留目录、阅读和已存结果。

# The Shelf 公开文档区域

产品、架构、实现顺序和设计决策使用公开文档区域提供给人和其他 AI。读取文档不需要进入私人管理后台，也不要求登录、浏览器脚本或 AI Key。

更新日期：2026 年 10 月 15 日。阶段：公开文档已实现，后续随网站迁移到 Cloudflare。

## 网页入口

网站导航增加产品与实现文档 section，入口为站点内的 /docs/。私人管理页面也链接到同一个公共入口，不另建需要账号的文档副本。

GitHub 项目站点可能有仓库路径前缀，所有文档与原文链接都以实际站点基路径生成，不能假设部署在域名根目录。

每篇文档生成可直接读取的 HTML 正文与稳定链接。页面包含标题、更新时间、设计或实现状态、目录和相关文档；不依赖 JavaScript 加载正文。

## AI 读取入口

| 入口 | 内容 |
| --- | --- |
| /docs/ | HTML 索引与阅读页面 |
| /docs/index.json | 文档 ID、标题、简介、版本、更新时间、HTML 与原文地址 |
| /docs/raw/ | 每篇文档的 UTF-8 Markdown 原文 |
| /docs/all.md | 按明确顺序合并的全部公开产品与实现文档 |

这些静态产物已实现。索引使用可访问的公开 URL，不包含本机路径。原文使用可识别的文本类型；更新后版本或内容校验值变化，方便其他 AI 判定缓存是否仍有效。

合并原文不含电子书正文、私人导入清单或内部运行日志。阅读文档既不调用模型，也不消耗 R2 书籍文件的访问额度。

## 内容源与发布

当前仓库 docs 目录中的公开文档是唯一内容源。网页、原文、索引和合并文档在同一次构建中生成，不在数据库维护另一份可编辑副本。

生成器使用明确允许发布的文件清单，不递归发布仓库所有文件。私人运维说明、凭证、本机路径、内部账号信息和电子书正文保存在其他位置。

设计约束与实际实现进度分别标记；接口、文件策略或权限发生变化时，同步更新相关文档与实现状态。未部署的能力不标为可用。

Workers Static Assets 根路径构建继续使用相同内容源、文档 ID 和固定发布清单，并针对目标 origin 重新生成链接；CF-02 验收器检查索引版本、全部文档链接和静态产物。目标站点线上验收通过前，GitHub Pages 仍是当前公开站。迁移不会把私人运维记录或电子书正文加入发布范围。

## 后续 MCP

未来可以在相同内容源上增加只读 MCP 读取能力，提供文档列表、按 ID 读取和文档搜索。文档使用稳定 ID 与版本，不把当前 URL 或本机文件路径作为唯一标识。

MCP 初期只处理公开文档。私人文件、个人对话、修改文档和消耗 AI 额度的操作不随公开文档资源一起开放。协议实现延后，当前先保证普通 HTTP 读取足够完整。

## 验收

匿名访问者和普通 HTTP 客户端能够取得文档索引、任意正文和合并原文。关闭 JavaScript 后仍可阅读；原文不包含密钥、本机绝对路径和私有数据。所有相关链接考虑项目站点路径前缀，并能对应同一版本内容。

## 技术与边界

当前静态网站采用 Astro 和 TypeScript，后端采用 Node.js 内置 HTTP 与 SQLite，导入使用 Python 标准库。运行需要 Node.js 24 及以上、Python 3.9 及以上；本机 PDF 文本准备可使用 pdftotext，MOBI 转换需可选的 Calibre。

迁移目标为 Workers Static Assets 托管静态网站、Workers 提供同源 API、D1 保存业务数据、Workflows 执行持久 AI 任务，继续使用现有私有 R2 桶。线上正文提取改为在 paw 导入时准备，再按文件选择同步到私有存储；AI 推理继续使用现有命名任务服务。paw 是开发和导入机器，不改为常驻生产后端。

代码与公开目录可以进入仓库；私人文件映射、SQLite 和原始私人状态留在被忽略的本机目录。云端仅同步业务必需的数据，密钥放入服务端秘密配置，正文与会话不得进入公开构建。保留现有 .local 人工修正、数据库和收藏源文件。

不增加现金支出，保持单文件 20,000,000 字节门槛、逐文件上传和 8,000,000,000 字节 R2 总预算；原文件、正文、派生文件与同账号其他占用均需计入。免费额度需按账号核对，不能把 R2 预算当成账单封顶。不为迁移开通付费计划。

## 页面设计

书架使用暖白背景、墨色正文和少量朱红强调色。左侧分类导航，主区提供搜索、格式与可用性筛选、紧凑书籍网格和分页。封面默认由书名、分类和颜色排版生成，避免导入未经确认授权的图片。移动端把侧栏收起为选择器。

详情页提供面包屑、书名与作者、分类和格式标签、完整文件列表、私人阅读入口、书内提问、章节与全书总结、作者资料以及已发布结果。每个格式单独显示大小和状态；未上传不显示可下载。页面会根据后端登录与能力状态展示可执行的操作。

公开文档区有目录侧栏、可直接读取的正文、原文与合并原文链接。所有页面支持实际站点基路径，无 JavaScript 时详情和文档正文仍可读。

# The Shelf 数据与接口契约

静态网站只消费经过筛选的公开目录和文档数据，后端单独读取私人文件映射。此契约统一导入、网页与后台实现，字段变更要同步消费方和验证。

更新日期：2026 年 10 月 14 日。阶段：开发契约。

## 公开目录

data/catalog.json 为公开输入，结构为 schemaVersion、generatedAt、sourceStatus、thresholdBytes、stats、categories、books。schemaVersion 为 1，thresholdBytes 为 20000000。sourceStatus 是 snapshot 或 scanned。

stats 包含 books、files、totalBytes、candidateBytes、candidateFiles、localOnlyFiles、invalidFiles。categories 是 id、name、count 的数组。

每本书包含 id、title、author（未知为 null）、category、categoryId、tags、description、files。id 为安全的稳定短标识，不能包含源路径。每个文件包含 id、format（PDF、EPUB、MOBI、AZW、AZW3 等大写格式）、sizeBytes、status、reason、visibility、readable。

status 使用 candidate、local_only、unavailable。candidate 仅说明大小合格且非空，仍未上传；local_only 说明因大小等原因只登记；unavailable 用于零字节等异常。reason 为 not_uploaded、size、empty 等明确原因。visibility 默认 private。readable 表示格式具备浏览器阅读能力（PDF 或 EPUB），不代表已授权或已上传。

public/data/catalog.json 可以复制公开输入。公开输出禁止 sourcePath、root、mtimeNs、textPath、storageKey、私人正文及任意密钥。

## 私人清单

.local/manifest.json 包含 schemaVersion、root、generatedAt、files。files 是以公开 file id 为键的对象，每项包含 path（源文件绝对路径）、bookId、format、sizeBytes、mtimeNs（十进制字符串）、eligibility（对应公开 status）、storageKey（缺省 null）、textPath（缺省 null）、visibility（缺省 private）。该文件必须被 Git 忽略。

后端验证真实文件仍在 root 内，非符号链接越界，大小与登记一致，文件非空且不超过门槛后才允许本机读取。大文件即使登录也不通过本地阅读接口绕过门槛。R2 文件使用 storageKey 映射，云端凭证只在服务端。

## 文档导出

scripts/export-docs.mjs 从明确列出的公开文档生成 data/docs.json 与 public/docs 的原文、合并原文和索引。

data/docs.json 包含 generatedAt、version、documents；每项包含 id、title、description、updatedAt、version、markdown、htmlPath、rawPath。README 的文档 ID 使用 overview，其他文件使用不含扩展名的文件名。网页路径为 docs 或 docs/id，rawPath 为 docs/raw/id.md；均是相对于站点基路径的路径。

public/docs/index.json 不含全文，仅输出稳定 ID、标题、简介、版本、更新时间和网页及原文路径。public/docs/all.md 合并全部白名单正文。索引由网页生成可访问的基路径版本，离线导出可保留相对地址。

## 后端配置与会话

后端默认只监听 127.0.0.1:8787。公共 GET /api/config 返回 apiConfigured、aiConfigured、r2Configured、localFilesEnabled、thresholdBytes。GET /api/health 返回 ok。GET /api/session 返回 authenticated 与 csrfToken（未登录为 null）。

POST /api/login 接收 password，成功返回 authenticated 与 csrfToken 并设置 HttpOnly 会话 cookie。POST /api/logout 结束会话。登录密码只从环境配置读取；未配置时不能登录。写请求验证 Origin，已登录写请求还验证 X-CSRF-Token。cookie 的 Secure 与部署域名由配置确定，跨域仅允许配置的网站来源。

## 文件与阅读

GET /api/books/id 返回该书公开目录及可用性，不泄漏源路径。GET /api/files/id/access 需要登录，返回 url、format、expiresAt、mode（local 或 r2）；未配置 R2 且未启用本地文件时返回不可用说明。

POST /api/books/id/metadata 需要登录与 CSRF，接收 title、author、description、tags 和 category；不允许 ID、文件路径或其他字段。成功返回 book，并保存私人覆盖记录及更新公开目录输入。重新导入保留这些修正。

GET /api/files/id/content 需要登录，返回本机文件并支持 Range、HEAD、安全文件名和 Content-Type。客户端通过 credentials include 使用此入口。EPUB 可以先 fetch 授权字节，再向阅读器提供 ArrayBuffer。

## AI 任务

POST /api/books/id/jobs 需要登录及 CSRF，接收 operation（question、chapter_summary、full_summary、author）、question、chapter（可选）、model（gpt-luna 或 gpt-sol），返回 202 和 job。

GET /api/jobs/id 返回私人任务状态；GET /api/books/id/history 返回个人结果；POST /api/jobs/id/publish 接收 published 布尔值，返回更新结果。GET /api/books/id/published 匿名可读主动发布的结果。

job 包含 id、bookId、operation、status（queued、running、completed、failed、uncertain）、createdAt、updatedAt、content、error、sources、published。输入保存在私人数据库，不返回日志。相同在途操作和输入去重。

服务端正文来自私人 textPath 或按需提取。PDF 使用 pdftotext，EPUB 按 spine 顺序读取 XML/HTML，MOBI 和 AZW3 需要先准备可用文本。未上传的大文件不会自动提取。长书全书总结分块逐段保存，按任务调用上限暂停；书内问答附来源。作者资料由独立允许的资料源获取，失败时不以模型猜测代替来源。

AI 调用只通过 /v1/tasks，使用 research_summary 或 topic_analysis，不使用旧聊天接口。请求 key、源文件路径和全文不返回公共网页。GET /api/books/id/published 输出专门筛选的公开字段。

## 环境与本机启动

需要 Node.js 24 及以上、Python 3.9 及以上。安装依赖后将 .env.example 复制为 .env，设置自己使用的所有者密码。空密码不会开放登录。不要把真实配置加入 Git。

```sh
npm ci
cp .env.example .env
npm run dev
```

前端默认为 http://127.0.0.1:4321/，后端默认只监听 http://127.0.0.1:8787/。在另一终端执行 npm run server。允许来源默认包含本机前端的 localhost 与 127.0.0.1 地址。

本机预览在未指定 PUBLIC_SHELF_API_URL 时连接本机后端；公开部署未配置这个值时，不会尝试访问访问者自己的本机服务。

## 导入私人收藏

```sh
python3 scripts/import-books.py --root /path/to/books
```

公开目录写入 data/catalog.json，私人文件映射写入 .local/manifest.json。私人映射中的 mtimeNs 使用十进制字符串，保留文件时间戳精度。重新导入保留 .local/overrides.json 中的人工元数据修正。

程序读取源目录，不移动、删除或写入电子书。不超过 20,000,000 字节且非空的文件进入大小候选，超过门槛的文件仅登记。大小候选未必完整，读取前再次验证路径、大小和修改时间。

SHELF_LOCAL_FILES_ENABLED=true 明确开启本机授权阅读。该功能只适用于后端能访问自己的收藏目录的机器，不把其他设备上的绝对路径当作云端文件。

## 后端会话与元数据

所有者在网页输入 SHELF_OWNER_PASSWORD 配置的密码，获得 HttpOnly 会话。写入需要受允许的 Origin 和会话 CSRF；密码和服务 Key 不在浏览器保存。

详情页登录后可展开整理书籍信息，修改书名、作者、分类、标签和简介。修正立即在当前详情显示，保存为私人覆盖记录，并更新允许公开的目录输入；静态书架通过下一次构建同步。

正式在线运行时，后端放在 HTTPS 反向代理之后，配置实际网页 Origin、SHELF_COOKIE_SECURE=true 和前端 PUBLIC_SHELF_API_URL。跨站会话受浏览器 cookie 策略约束，优先使用同一主域下的站点与 API。

## 按需 AI

配置 SHELF_OAI_BASE_URL 与现有任务服务接受的 SHELF_OAI_KEY。Key 只保存在后端；新任务服务使用环境配置 Key，不直接使用旧管理页数据库签发的 Key。

导入、打开页面和搜索不会调用模型。书内问题使用相关正文，章节与全书总结按真实范围处理，作者资料只根据可以确认身份的公开资料生成。未知作者可以先人工补齐；无法核实的资料会明确失败，不生成猜测的事实。

默认每日最多 20 次任务服务请求，每个业务任务最多 12 次调用，并发为 1。长书先检查汇总所需调用数，超出预算时不调用模型；繁忙拒绝只有限重试，结果不确定时不自动重发。

私人结果默认不公开。所有者点击发布后才出现在详情页公共结果区域。公开访问者不能触发新的 AI 请求。

## R2 配置与预算

没有 R2 时保持相关配置为空。配置后仍不自动上传；上传必须明确选择 file ID，CLI 默认只生成计划。

```sh
npm run upload:plan -- file_example
```

传入 --execute 才执行实际上传。执行前验证文件门槛、现有注册占用、其他占用和未确认的上传预留。总预算默认 8 GB；超预算继续只登记。SHELF_R2_EXISTING_BYTES 记录未包含在当前私人清单中的已占用容量。

上传结果不确定时保留预留记录，不能直接删除记录然后重发。先核对远端对象与大小，再确认私人映射。当前没有网页上传管理和自动账单封顶。

对象存储设置必须允许实际网页来源读取文件及 Range。网页读取签名 R2 地址不附带 cookie，本机内容接口附带所有者会话；签名链接到期后重新申请。

## GitHub Pages

## 文档读取
