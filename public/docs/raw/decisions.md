# The Shelf 设计决策

决策记录明确区分用户已确认的要求与实现时可以调整的选择。未来参与项目的 AI 应先遵守已确认约束，再评估具体技术方案。

更新日期：2026 年 10 月 15 日。阶段：首版已实现，追加 Cloudflare 迁移计划。

## 已确认的要求

| 决策 | 理由与效果 |
| --- | --- |
| 书架公开，文件默认私有 | 展示收藏，按具体许可决定是否开放文件 |
| 超过 20 MB 的文件暂不上传 | 大文件仍保留详情、大小和格式 |
| 大小门槛按文件执行 | 同一本书的小 EPUB 可独立上传 |
| 导入不默认生成 AI 总结 | 避免大量不必要调用 |
| 优先详情页按需 AI | 支持书内问题、总结和作者资料 |
| 不增加现金支出 | 优先已有基础设施与免费额度，超预算继续只登记 |
| 产品与实现文档公开 | 其他 AI 可通过普通网页或原文读取 |
| MCP 留作后续 | 当前先提供稳定 HTTP 文档入口 |
| 复制中的目录先只读盘点 | 不干扰正在进行的复制 |
| 将 Cloudflare 统一托管纳入后续计划 | 先验证免费运行，再逐步迁移网站和业务后端；GitHub 继续保存代码 |

## 暂定实现选择

静态前端使用 GitHub Pages，文件使用 R2 Standard，业务后端为独立 Node.js 服务，数据与任务使用 SQLite。生产后端部署位置尚未选定，paw 用于开发。超过门槛、超预算或复制未完成的文件都能被目录收录。

以上为现有实现。后续目标方案采用 Workers Static Assets、Workers、D1、Workflows 和现有私有 R2；生产部署以免费适配验证结果为准，目前尚未迁移。不把已有 Node.js 后端直接改成 paw 上的生产常驻服务。

大小单位暂按十进制 MB；本项目存储预算初设 8 GB，实际额度还要扣除同一账号其他占用。所有者独立登录，匿名访问者不开放 AI 生成。

公开文档使用仓库 Markdown 内容源，构建 HTML、原文、机器索引与合并原文。库内所有文档不自动公开，发布范围由允许清单确定。

## 下一阶段需要核实的状态

收藏复制已确认完成，已生成真实目录；R2 凭证与诊断对象读写已验证。下一阶段先核实 Cloudflare 免费计划、账号共享额度、项目部署权限、Workers CPU、D1 容量及长任务执行，再完成真实文件阅读与 AI 接入。实际站点地址和切换时机在迁移阶段确定。

现有所有者密码登录继续保留业务语义；首批验证使用逐文件选择的合格 EPUB 与 PDF。AI 专用 Key 与现有服务接口验证独立处理。不为迁移购买新域名或付费计划，不修改收藏源文件。各任务依赖和验收见[开发计划](development-plan.md)。
