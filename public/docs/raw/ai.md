# The Shelf AI 问答与总结

AI 按所有者请求执行。导入只准备文件和检索数据，打开页面只读取已有结果。书内问答、全书总结和作者资料使用不同的材料来源。

更新日期：2026 年 10 月 21 日。阶段：本机 Node 任务实现；真实 Key 成功调用验证待完成，云端迁移待验收。

## 现有服务接入

oai-api 当前使用 POST /v1/tasks 命名任务接口。输入是纯文本，返回 content 字符串、上游 turn ID，以及可能为 null 的 token 用量；未知用量保持未知，不按零处理。kind 只作兼容标签，不选择提示词或输出结构；业务指令由 instructions 提供，需要 JSON 对象时显式设置 output_format 为 json_object。模型只接受服务端公布的别名。接入时验证返回值，不把模型输出直接当作可信业务数据。

现有服务每次创建独立临时会话，不读取书籍文件，不自动抓取 URL，不联网检索，也不提供连续对话、业务任务查询或结果恢复。服务限额与请求约定见 [公开接入指南](https://oai.parallelstreamllc.com/guide)。

输入最多 500,000 个 Unicode 字符，instructions 最多 50,000 个 Unicode 字符；编码后的整个 UTF-8 JSON 请求体默认不超过 32 MiB。这些只是接口上限，不等于模型可用上下文。共享服务全局并发为 1，服务端任务期限为 840 秒，客户端等待期限为 900 秒；繁忙时可能返回 503 和 Retry-After。书库当前只在单个 Node 进程内串行执行，不构成跨进程或跨应用的全局并发控制。

上游流式接口允许任何最终输出为文本的任务类型；但书库适配器当前使用非流式请求。第一版显示业务任务进度和完成后的回答。

## 专用 Key

书库使用独立命名 Key，只保存在业务后端。当前任务服务验证环境配置中的 Key，旧管理页数据库签发的 Key 不能直接用于新任务入口。

Key 提供调用归属，不等于书籍权限、用户登录或独立配额。所有者登录、每日调用限制和任务预算在书库后端实现。签发与部署配置属于实现阶段，不在设计阶段执行。

## 书内问答

本机已接入显式选择的正文包，校验来源、版本及全部内容 hash 后再交给任务。未选择包时保留既有私人正文路径。查询与检索副本采用 NFKC 和大小写归一，中文使用相邻双字、英文使用词项，按稀有度和长度排序，最多选择五块；原文与定位不做检索归一。按书籍范围结合相关段落和已有回答准备材料。回答提供章节或 PDF 页码来源；EPUB 使用章节与稳定定位，避免虚构固定页码。

找不到依据时说明无法从已准备正文确认，不把模型已有知识伪装成原文。只登记而未准备正文的书不开放书内问答；用户可另行请求作者资料或背景研究。

书中出现的指令、网址和提示词按材料处理，不改变系统约束。私有书籍的正文片段与问答记录不进入公共缓存。

## 全书与章节总结

章节总结只处理按正文顺序选定的一个非空章节（PDF 为一个非空页）。全书总结按材料长度和调用预算分组，保存中间结果后生成总览，分组及总览材料保留来源引用。任务记录所选与已完成块数；空页或空章节不会改变真实页码或 spine 位置。按修改章节增量重算仍是后续目标。

目录、前言或节选可以生成内容概览，但不能标为全书总结。长书任务显示覆盖范围、预计调用次数和额度提示；超过项目设定上限时缩小范围或暂停，不能悄悄启动无限分块任务。

## 作者资料

作者生平需要独立的资料获取步骤，优先使用可以确认作者身份且允许使用的公开来源。记录来源 URL、获取时间和适用许可，再让现有 AI 服务根据资料整理。

同名作者需要结合作品、语言和年代核对。资料不足时显示已有事实及缺口，不由模型补齐不存在的来源。没有正文的书也可以使用此能力。

## 保存与发布

任务成功后默认保存为所有者私有记录。正式总结和对话记录分别存储，所有者主动选择后才生成公共版本。公开版本保留出处和覆盖范围，避免发布大段原文。

在途去重标识包含选定正文版本、来源指纹、操作类型、章节范围、问题与模型。选中版本在任务创建时固化，重启后仍保留；改选默认版本不会改变已排队任务的来源。声明版本不可用时任务明确失败，不回退其他正文。缓存复用必须先验证访问权限；普通问题不只靠相似问题文本自动复用不同语境的回答。

## 队列与额度

书库建立有上限的持久队列，初期只在本机单个 Node 进程内串行调用 AI。相同在途业务任务去重，页面刷新和重复点击不创建新的调用；遇到服务忙碌时不会自动按 Retry-After 重发。

书库对上游调用不做自动重试，包括 503 忙碌响应。超时、断线或其他结果不确定的情况标记待确认，不自动重新调用。未知状态会暂停已有队列任务和新任务；进程重启或队列恢复不会清除此暂停状态，需先完成状态核对。现有服务没有上游幂等或恢复能力，不能承诺每个任务严格只执行一次。

使用已有订阅服务控制调用与额度占用，不自动购买官方 API 余额、向量服务、联网检索套餐或其他模型订阅。需要付费依赖时先暂停该能力，保留目录、阅读和已存结果。
