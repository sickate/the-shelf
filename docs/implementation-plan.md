首版目录、文档、私人阅读与 AI 后端已实现并通过本地验证。后续先验证 Cloudflare 免费运行条件，再迁移网站与业务后端，完成真实阅读和 AI 接入。任务编号和优先级以[开发计划](development-plan.md)为准。

更新日期：2026 年 10 月 15 日。阶段：首版已验证；CF-02 实现待主 Agent review 和新站验收。

以下阶段验收条件继续适用；已实现的基础功能无需重新开发。

## 阶段一 收藏盘点

复制稳定后按扩展名、文件大小和路径汇总，计算超过与未超过 20 MB 的数量、字节数。分清书籍与文件，识别可能重复、多格式和版本差异。

输出私人完整清单与可公开的聚合结果。复制未结束时结果标为暂态，不能作为上传最终计划；这一阶段只读源目录。

## 阶段二 公开书架和文档

实现分类书架、搜索、详情与文件状态。所有登记文件均显示格式和大小，超过门槛的文件标记仅本地保存。同步生成公开 docs 网页、原文、索引与合并文档。

验收要求：无云端文件的书也有详情页；多格式分别显示状态；公开页面不暴露本机路径和私人数据；文档匿名可读。部署包不含电子书正文。

## 阶段三 免费额度内的私人文件访问

配置个人登录、私有文件存储、上传预算和短期访问授权。优先上传适合网页阅读的小文件；超预算文件继续登记。转换与完整性验证在本机执行。

验收要求：未登录无法读取私人文件；登录后 PDF 与 EPUB 可阅读下载；链接过期可刷新；上传计划计入派生文件与现有占用；超额时停止上传而非升级付费。

## 阶段四 按需 AI

配置专用后端 Key、中文正文检索、个人历史、持久任务队列、问答与章节总结，再增加全书总结和有来源的作者资料。

验收要求：导入与页面访问不调用 LLM；无正文时不生成书内回答；重复点击去重；忙碌时有限等待；浏览器关闭后任务可继续；结果不确定时不盲目重试；私人结果只有主动发布才公开。

## 阶段五 后续能力

先完成 Cloudflare 迁移：CF-01 免费后端验证 → CF-02 静态网站 → CF-03 登录与私人阅读 → CF-04 本机正文准备 → CF-05 持久任务与真实 AI → CF-06 可靠性与后续体验。

验收要求：新站点静态链接与文档机器入口有效；同源 API 保留登录、CSRF、文件权限与发布边界；D1 与私有 R2 中的数据可核对和恢复；任务在页面关闭后继续且不盲目重试上游；实际运行符合免费额度。GitHub Pages 在新站验收前继续服务，迁移不覆盖现有私人数据。

主流程稳定后，再根据实际使用增加跨设备阅读进度、网页上传管理、更好的正文检索与只读文档 MCP。书籍问答流式输出需要明确扩展现有 AI 服务契约，不挪用作文批改任务。

任何新增能力仍受不增加现金支出的约束。没有免费且适用的依赖时延后该能力，不影响已完成的目录、文档和阅读功能。
