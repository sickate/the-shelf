# The Shelf 产品与实现文档

The Shelf 的书架和设计文档公开，电子书默认私有。所有文件都进入收藏目录；超过 20 MB 的文件暂不上传，详情页仍显示格式、大小和可用状态。AI 仅在主动提问或请求总结时调用。

更新日期：2026 年 10 月 14 日。阶段：首版开发。产品需求与架构描述目标，实际能力和待配置项以运行与部署说明为准。

## 当前实现范围

先统计收藏，再确定免费额度内的上传候选。随后实现公开目录和文档、个人阅读与下载、按需问答与总结。导入默认不调用 LLM，不购买服务器、数据库、模型额度或其他订阅。

本目录只包含可公开的产品与实现说明。实际密钥、账号配置、本机路径、私有文件清单、正文和个人问答不属于公开文档。
