# The Shelf 设计决策

决策记录明确区分用户已确认的要求与实现时可以调整的选择。未来参与项目的 AI 应先遵守已确认约束，再评估具体技术方案。

更新日期：2026 年 10 月 13 日。阶段：设计。

## 已确认的要求

| 决策 | 理由与效果 |
| --- | --- |
| 书架公开，文件默认私有 | 展示收藏，按具体许可决定是否开放文件 |
| 超过 20 MB 的文件暂不上传 | 大文件仍保留详情、大小和格式 |
| 大小门槛按文件执行 | 同一本书的小 EPUB 可独立上传 |
| 导入不默认生成 AI 总结 | 避免大量不必要调用 |
| 优先详情页按需 AI | 支持书内问题、总结和作者资料 |
| 不增加现金支出 | 优先已有基础设施与免费额度，超预算继续只登记 |
| 产品与实现文档公开 | 其他 AI 可通过普通网页或原文读取 |
| MCP 留作后续 | 当前先提供稳定 HTTP 文档入口 |
| 复制中的目录先只读盘点 | 不干扰正在进行的复制 |

## 暂定实现选择

静态前端使用 GitHub Pages，文件使用 R2 Standard，业务后端复用已有服务器，数据与任务使用 SQLite。超过门槛、超预算或复制未完成的文件都能被目录收录。

大小单位暂按十进制 MB；本项目存储预算初设 8 GB，实际额度还要扣除同一账号其他占用。所有者独立登录，匿名访问者不开放 AI 生成。

公开文档使用仓库 Markdown 内容源，构建 HTML、原文、机器索引与合并原文。库内所有文档不自动公开，发布范围由允许清单确定。

## 实现前需要核实的状态

收藏复制是否完成、上传候选实际体积、同账号剩余 R2 免费额度、已有服务器运行余量，以及线上 oai-api 与当前源码的接口一致性。

登录方式、已有域名的使用、首批上传优先顺序和具体文件许可，在实现对应阶段确定。核实这些状态不应触发付费开通、密钥签发或源文件修改。
