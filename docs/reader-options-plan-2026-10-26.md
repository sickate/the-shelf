# 阅读页：单页/双页切换与阅读选项（2026-10-26）

用户需求：阅读页增加单页/双页显示开关；对支持重排的格式增加字体等常规阅读选项。

## 范围

| 格式 | 单/双页 | 阅读选项 |
| --- | --- | --- |
| PDF（pdf.js） | 单页 / 双页（并排两页；首页单独作封面可选“封面单独”） | 缩放已有；不重排，不提供字体 |
| EPUB（epub.js） | `spread: none / always` | 字体、字号、行距、页边距、主题、翻页/滚动 |
| MOBI/AZW3（foliate-js） | `max-column-count` 1 / 2 | 同上 |
| TXT/MD | 不适用（滚动） | 字体、字号、行距、主题 |

- 单/双页开关在工具栏直接可见（`单页 | 双页` 分段按钮）；窄屏（< 900px）自动单页且开关禁用并提示。
- 阅读选项放在工具栏“Aa”按钮弹出的面板中：
  - 字体：默认（书内字体）/ 宋体衬线 / 黑体无衬线 / 楷体；只用系统字体栈，不加载外部字体。
  - 字号 60–200%（沿用 `shelf:epub-font`），行距 1.2–2.2，页边距 窄/中/宽。
  - 主题：跟随系统 / 浅色 / 护眼（米黄）/ 深色。
  - 排版方式：分页 / 连续滚动（EPUB、MOBI）。
  - “恢复默认”。
- 偏移位置（进度）切换布局后保持在当前章节/页。
- 设置存 `localStorage`（键 `shelf:reader-prefs:v1`，try/catch），所有格式共享，PDF 只读其中的单/双页与主题背景。
- 明确不做：PDF 文字重排、自定义字体上传、按书单独保存设置、服务端同步。

## 分工

| # | 任务 | 模型 | 依赖 |
